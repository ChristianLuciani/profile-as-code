`profile-as-code`, `pasco` and the mark (the disc with the p, the eye and the smile) are
marks of Christian Luciani. The source code is licensed MIT; this policy covers the
marks, not the code.

## Scope

- **Covered:** the names, the mark, the tile, the lockup and the wordmark.
- **Not covered:** the software, the schema and the docs. Those are MIT — see
  [`LICENSE`](LICENSE).

## Allowed without asking

- Referring to the project by name in articles, talks, courses and documentation.
- Linking to the repository or the project page.
- Reproducing the unmodified mark, or an unmodified screenshot of the project page, to
  identify the project in editorial coverage, comparisons or tutorials.
- Keeping the files in a fork of this repository, as long as the fork is not presented
  as the official project.

## Not allowed without written permission

- Using the names or the mark as the name or logo of another product or service.
- Modifying the mark's geometry, or using colours outside the palette in
  `site/brand/BRAND.md`.
- Any use that suggests sponsorship, endorsement or affiliation.
- Merchandise, or use as a trademark in commerce.
