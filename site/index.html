Your professional identity, as code.

profile-as-code is a versioned source of truth for your professional identity: your facts live once in YAML, and the engine renders consistent, platform-specific texts for GitHub, LinkedIn, Upwork, X, and other surfaces. It is for technical people who would rather maintain one folder than eight profiles by hand. Install the CLI, run pasco init, and keep every profile in sync from one place.

Install from npm Start here Read the user guide

Node.js ≥ 22. No account and no repo are required for on-ramps B and C.

Why

One source of truth. Every surface.

The same profile lives across many platforms, each with its own rules, limits, and audience. Edited by hand, the copies drift, and the facts (dates, roles, publications) start to contradict each other. profile-as-code gives those facts a versioned home and makes the rendered texts a deterministic output of it.

01

Facts stay facts

Dates, roles, projects, and publications are structured data validated against a JSON Schema. Drift checks warn when a fact disagrees across platforms; schema violations fail.

02

Texts are angles, not copies

Bios and headlines are authored per platform and language, and rendered as deterministic base texts. The engine does not invent facts: it renders the ones you declared; the variant picker is still partial.

03

Consistency is citability

Search engines and language models read and cite profiles. Identical facts across surfaces, semantic anchors, and structured data are what make a profile quotable.

Start

Three on-ramps. The same engine.

Your workspace is a folder; a repository is the recommended place to keep it, not a requirement. Pick the one that matches what you already have. The three paths share the same folder contract and the same pasco commands — they differ in automation, history, and whether an account is involved.

Status

Pre-1.0. Published. Honest.

The engine is usable today, and it is still growing. This page states what works and what does not, so you can decide before you invest time.

Package

@profile-as-code/cli@0.3.6 is published on npm and installs with npm i -g @profile-as-code/cli.

Works

init, validate, build, diff, status, and the offline rules of check. Renderers: GitHub profile and organization, plus the paste family.

Partial

refine emits the agent task and records the chosen variant; the full variant flow is still on the roadmap. The platform rule catalogue continues to grow.

Not in v1

A hosted profile with no account and no terminal is a declared non-goal, with an explicit reopening trigger in the specification.

The authoritative command table lives in the CLI README; the milestone plan lives in the roadmap.
