# SOTA Ko-fi — research versionado (2026-10-05)

Research date: 2026-10-05 (UTC). Same date for every source (each URL fetched
2026-10-05). Tags: `[OFICIAL]` = Ko-fi's own docs/pages (primary) · `[WEB]` =
primary URL fetched (incl. via mirror) · `[BENCHMARK]` = real-profile
observation · `[?]` = not calibratable / not documented.

Method / caveats: discovery ran through Ko-fi's own help-center search API
(`help.ko-fi.com/api/v2/help_center/articles/search.json`, en-US, all 120
articles) plus direct fetches. `ko-fi.com` and `help.ko-fi.com` pages are
Cloudflare-challenged for plain HTTP fetch (HTTP 403); public page content was
verified through a headless reader mirror (`r.jina.ai/<url>`) and marked
`[WEB]`. `developers.ko-fi.com` does not resolve (NXDOMAIN) — Ko-fi documents
webhooks, not a management API ([OFICIAL S18]).

## 2. Formatting of the About/bio text

- The WYSIWYG toolbar (styling, links, embeds, images) is documented for
  **Posts** (feed/blog), not for the profile bio: "Use the toolbar to control
  the styling of your text and layout, add links, embed videos and images". [OFICIAL S14]
- For the **bio/About card itself**: no documented markup support found (no
  markdown/HTML mention in any read article) → write **plain text**. [?]
- On a live page (ko-fi.com/webby), the About text rendered as one plain-text
  run; the email inside the bio was NOT rendered as a clickable anchor, while
  the social links right below (bio page, X, YouTube, Twitch, TikTok) were
  real anchors. Bio lines longer than a few lines collapse behind "Show
  more". [BENCHMARK/WEB S12]
- **Links:** the official way to link out from the About zone is the
  Social-links feature (up to 15, anchored with icons), not inline links in
  the bio. Custom/unrecognized sites show a standard link icon; several
  custom links drop into a dropdown. [OFICIAL S3]
- **Line breaks:** no official statement; on S12 the creator's bio was a
  single run visually — assume breaks not guaranteed. [?]
- **Emoji:** explicitly supported in status ("Yes, you can add an emoji
  alongside your custom status text"); Ko-fi copy itself uses emoji in bios
  on marketing pages. [OFICIAL S1] — `[?]` for the bio field itself.

## 3. URL / identity

- Canonical pattern: `https://ko-fi.com/<username>`, with subpaths `/tiers`,
  `/shop`, `/commissions` (official list in S9; observed also `/gallery`,
  `/posts`, `/goal`). Help pages use `ko-fi.com/<em>yourusername</em>`. [OFICIAL S9, S16]
- "Claim" language: Ko-fi's own copy — "claim your free page" (sign-up CTA);
  the handle is chosen at claim time. [OFICIAL S10]
- Rename: "you can change your Ko-fi username any time, and your QR code will
  still work and link to your page" [OFICIAL S6]. Observed consequence: old
  handle paths keep resolving — one creator's page served identical content
  at both ko-fi.com/webby and ko-fi.com/peterwebby (same profile id);
  profiles are also internally addressable by opaque id. [WEB S12][BENCHMARK]
  → **rename-drift risk**: a pasted bio/URL may carry a stale handle; always
  verify which handle is live before pasting.
- Social preview can retain an old/dead name after rename (help labels it
  "deadname"; fix = re-generate preview in Page settings). [OFICIAL S4]
- Privacy/unpublish: pages have **no documented self-service hide/unpublish
  setting**. "Unpublished" = Ko-fi-side suspension (strikes/three-strike
  system; Trust & Safety review). Page-level **NSFW tag** exists. [OFICIAL S7, S8]
- Host nuance: `kofi.com` (no hyphen) and `www.kofi.com` **do not resolve at
  all** (DNS lookup `ENOTFOUND`, 2026-10-05). Only `ko-fi.com` serves pages —
  identity URLs and handle checks must use the hyphenated host. [WEB S17]

## 4. Visibility / SEO

- robots.txt: `User-agent: *` disallows only `/Administration/`, `/Manage/`,
  `/api/`, `/design-system/`, `/streamalerts/overlay`(+animated/goaloverlay).
  Creator pages `/<handle>` are **not disallowed** → crawlable by default.
  [WEB S11]
- Public search/directory: `ko-fi.com/explore` renders the logged-out landing
  (no browsable creator directory/search in that path); Ko-fi states post
  tags "are not for searches now, but will be handy when we improve the tag
  function". No public profile-search is documented in the help center. [WEB S13] [OFICIAL S14] [?]
- Documented discoverability: none beyond external promotion. Ko-fi actively
  bans "mass SEO abuse (commercial spam)" pages. [OFICIAL S8]

  expect ~403 on raw requests. [WEB S12]

## 6. Deploy (manual paste flow) — dashboard paths [OFICIAL unless noted]

- Account-level: **Settings** (sidebar) → **Profile** tab
  (`ko-fi.com/settings?tab=profile`): display name + "Your social links"
  (add/remove, Save). [OFICIAL S3]
- **Settings → Page** tab (`ko-fi.com/settings?tab=page`): "Set your preview
  image and text" → "Customize preview"; **Page focus** dropdown (default
  landing tab: Feed/Memberships/Shop/Commissions); custom color;
  coffee-counter toggle. [OFICIAL S4, S16]
- Your page: **`ko-fi.com/manage/mypage`** → top-right three-dots → "Set
  Cover Image"; About content lives on the page's **About** area ("Your
  about page > Add Something" pattern per the Posts/Polls articles). [OFICIAL S5, S14, S15]
- Status: page → "Set a status" next to profile pic → text (≤40) + emoji +
  "Clear after" → Save. [OFICIAL S1]
- Paste-checklist reference order: name → status → bio/About text → social
  links → preview text/image → page focus → cover image.

## 7. Short vs long bios

- The page loads half-way down the cover image "so that your visitors can get
  straight to your main content" — the About text is on the default (About)
  tab and truncated behind "Show more" when long. [OFICIAL S5] [WEB S12]
- The only guaranteed short-slot line is the **status** (≤40 chars) next to
  the name (also at checkout and in DMs). [OFICIAL S1]
- Link shares are governed by the customizable social preview text/image,
  independent of the About text. [OFICIAL S4]
- No documented per-field limit for About → the engine treats About as
  unbounded, with renderer/skill-side soft caps. [?]
